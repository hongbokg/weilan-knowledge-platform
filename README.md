# 蔚蓝知识库平台

将企业 NAS 中的标书、技术资料、公司资质和历史报价，整理为可搜索、可追溯的知识。员工继续使用 NAS 管理原文件，平台通过只读账号增量同步，识别正文与表格，再提供检索和问答入口。

本项目是 **WeKnora 集成与部署扩展**，包含当前 CPU/GPU 文档流水线、质量补识别、监控组件、WeKnora 源码补丁、自动分库与产品库模块、摘要助手及原生 Android 客户端源码。第三方完整程序、模型权重、驱动和数据库数据不在包内。

## 主要能力

- **NAS 增量同步**：每三天检查一次；保存文件目录、路径、修改时间与状态，MD5/SHA256 跟踪内容，相同内容复用解析结果，不同知识库保留各自权限和身份。
- **CPU 与 GPU 分流**：可靠的电子 PDF 在 CPU 提取文字和表格；扫描件、混合页和不确定版式送 MinerU GPU。大 PDF 分页处理、保存检查点，每批十个新页让出队列。
- **有界并发**：文档通道与推理上下文分开；两路 GPU 推理池限制等待请求、内存和超时，避免文件洪峰冲击显存。
- **质量隔离与补识别**：识别不足、空表格、超限和转换失败按原因记录。图片漏字可使用独立 CPU PaddleOCR 补识别；低置信度、表格和密码内容不能直接放行。
- **来源追溯**：保留 NAS 路径、文件名、内容版本和实际定位。PDF 页码、表格行列、图片坐标按解析结果保存；缺失定位保持空值。
- **业务资料整理**：公司和项目目录分库、历史产品和报价结构化，以及型号与参数证据比较。目录不明确的资料不能凭推测归属公司。
- **可观察运行**：CPU/GPU/内存曲线、文件状态、合格页速率、队列等待和失败原因。缺少可靠数据时显示未知，不伪造完成时间。
- **移动与专家接入**：原生 Android 文档卡片、图片预览和文件分享；通过鉴权 API/MCP 接入 WorkBuddy、Codex、飞牛 Octop。

## 快速开始

适用于 Ubuntu 24.04 / Python 3.12。先准备可用的 WeKnora、MinerU jobs API、归档文件系统与 noswap tmpfs；Office 转换还需要 AnyDoc 适配器。新机器的依赖安装见 [安装说明](docs/安装与升级.md)。

```bash
python3 installer/install.py plan
sudo bash install.sh install
# 使用私密终端填写 config.json，权限 0600，勿提交到 Git。
# 完成归档 UUID、tmpfs、目标库和只读 NAS 配置后：
sudo /opt/weknora-nas-sync/.venv/bin/python installer/install.py preflight
sudo /opt/weknora-nas-sync/.venv/bin/python installer/install.py activate
```

安装器先校验文件哈希，默认不启动任务，也不替换已有服务。同名目录、配置或 systemd 单元已存在时停止，现有生产环境按升级说明处理。本项目不是包含全部依赖和模型的离线一键镜像。

## 安全与数据

真实 API 密钥、NAS 账号、数据库、模型权重、原件、APK 签名私钥及私有调试图不进入公开仓库。源码示例使用 `kb.example.com`，部署时换成自己的地址。公司密码内容隔离规则需要配合实际资料验证；任何 OCR 都可能漏字，不能视为绝对敏感信息识别保证。

Wiki 只对手动指定的重点项目生成；摘要按需生成并缓存。当前本地 BGE-M3 向量化与云端 HY3/GLM 摘要是不同环节，在线 embedding 不会替代 OCR，也不能与其他模型向量混写同一索引。
