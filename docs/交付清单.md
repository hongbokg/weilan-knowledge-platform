# 交付清单

| 路径 | 内容 | 自动安装 |
|---|---|---|
| install.sh installer | 哈希校验、安装、预检与启用 | 是 |
| server/pipeline | 当前解析分流、台账、补识别、推理池、监控源码与测试 | NAS 核心任务 |
| server/weknora-overlay | 固定基础版本的 WeKnora Go Vue 补丁 | 单独检查及应用 |
| server/anydoc-worker | 独立 Office CPU 适配器源码 | 按说明构建 |
| server/organization | 公司项目分库、产品与历史报价结构化 | 参考集成 |
| server/operations summary-assistant | 摘要回填与 OpenClaw 助手源码 | 参考集成 |
| mobile | 原生 Android 客户端源码及可移植构建入口 | 自有 SDK 签名 |
| connectors | MCP API 接入契约和脱敏示例 | 客户端配置 |
| docs | 平台介绍、特色、蓝图、运维记忆、部署与验收边界 | 文档 |

真实公司资料、服务器配置、密钥、私有记忆全文、运行数据库、模型权重、完整第三方仓库、旧商业 KB 平台和签名密钥均不在公开包内。服务器快照仅提取代码，公开源码中的部署域名替换为示例地址；原生产代码与现有 APK 没有因此改动。

本包覆盖本轮允许公开的当前代码和集成补丁，不等于 R740 虚拟机磁盘镜像，也不等于所有历史调试目录的完整复制。
