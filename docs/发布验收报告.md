初次 Linux 回归缺少独立模块的 cv2、httpx 和 pool_guard 测试路径，补齐依赖来源和工具文件后 89 项通过。安装包的主同步依赖、独立 GPU relay 依赖和图片补识别依赖仍保持分开，不把模型服务安装进主同步 venv。

每个文件的 SHA256 在 MANIFEST.json 与 SHA256SUMS 中；压缩包 SHA256 单独交付。公开源码默认部署域名为示例地址。可选图片补识别、监护、自动分库、产品和摘要模块需按说明配置及小批验证，首次安装不会自动启动这些模块。
