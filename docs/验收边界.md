# 验收边界

## 既有生产证据

- A2 两个独立视觉推理上下文，59 页固定样本对照由 1085.886 秒至 504.268 秒，文字、表格、坐标及质量标记一致。属于这组样本结果，不是全库速度或其他显卡的保证。
- 洪峰模拟限制两个推理请求、八个等待请求；请求超时不代表底层 CUDA 推理已经被强行中断。
- CPU 图片补识别 12 项测试和同步发布 23 项回归通过；两份版本恢复索引，其中一份对照原图并通过新文字的业务 API 检索。复杂表格和低置信度内容仍隔离。
- Android 历史版本曾完成构建、签名和协议检查，公开源码已改为示例域名，需要重新构建、自有签名和真实手机验收，不能把这些历史结果当作公开安装包真机验收。

## 发布包的验收

以 release-validation.json 为准，记录源码编译、安装器 staging、哈希检查、凭据扫描与 Linux 回归结果。首次 staging 只写临时目录，不启动生产 timer，不写 NAS、不调云端模型。
